# API de Tarefas

API simples desenvolvida com **Node.js** e **Express** para gerenciamento de tarefas.  
Ela permite cadastrar, listar, buscar, atualizar e excluir tarefas armazenadas em memória.

## 📌 Sobre o projeto

Este projeto é uma API REST para controle de tarefas.  
Ela pode ser usada para fins de estudo, prática de rotas HTTP, manipulação de dados com Express e organização básica de uma aplicação backend.

A API trabalha com uma lista de tarefas em memória, ou seja, os dados são apagados sempre que o servidor é reiniciado.

## 🚀 Tecnologias utilizadas

- Node.js
- Express
- Dotenv

## 📁 Estrutura principal

O projeto possui uma API com as seguintes funcionalidades:

- Verificar se a API está funcionando
- Cadastrar tarefas
- Listar todas as tarefas
- Buscar uma tarefa pelo código
- Atualizar uma tarefa
- Excluir uma tarefa
- Excluir todas as tarefas
